# BOSSFALL

테트리스의 줄 제거 공격을 보스전으로 바꾼 180초 보스러시 웹 게임입니다.

## 실행과 검증

Node.js 22 이상에서 저장소 루트의 다음 명령을 실행합니다.

```sh
npm ci --ignore-scripts
npm run check
npm test
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `/health`는 서버 상태를 반환합니다. 별도 데이터베이스와 API 키는 필요하지 않습니다.

## 플레이

- 솔로 / 같은 기기 2인 / 온라인 방 코드 2인 플레이.
- 협동: 공동 보스 HP, 난이도별 보스 제한 시간. 탈락한 동료가 있어도 생존자는 계속합니다.
- 경쟁: 공동 보스의 막타가 상대에게 방해 블록 2줄을 보냅니다. 개인 데미지를 결과로 표시합니다.
- 줄 제거 1 / 2 / 3 / 4줄은 25 / 65 / 110 / 180 데미지. 연속 줄 제거 콤보당 10 추가.
- 보스: 6초 뒤 사라지는 유령 블록, HOLD 봉인, 가속 낙하, 방해 블록 등장. 4종이 순환하며 HP가 상승합니다.
- 입문 / 일반 / 악몽. 기록은 모드·난이도·인원과 함께 브라우저에만 저장합니다. 공개 서버 랭킹은 없습니다.
- P1 및 온라인: 방향키, SPACE, C. 로컬 P2: WASD, F, Q. 화면 터치 버튼도 지원합니다.

보드는 표준 SRS 전체 구현이 아닌 간단한 회전·벽 보정 규칙을 사용합니다. 초기 프리뷰이며 계정, 매치메이킹, 관전, 서버 영구 기록은 후속 개발 대상입니다. 온라인 방은 메모리에 저장되어 서버 재시작 시 사라집니다.

## 배포

`.github/workflows/pages.yml`은 main 푸시 시 테스트 후 `public/`을 GitHub Pages에 배포합니다. 저장소의 Pages 소스를 GitHub Actions로 활성화해야 합니다. Pages는 솔로와 같은 기기 2인용 정적 클라이언트를 제공합니다.

온라인 파티는 WebSocket을 지원하는 Node 서비스가 필요합니다. `render.yaml`을 Render Blueprint로 연결하거나 Dockerfile로 서버를 배포합니다. 서버가 클라이언트 파일까지 제공하므로 해당 서비스 주소에서 바로 온라인 플레이가 가능합니다. Pages에서 온라인을 이용하면 로비의 서버 주소에 해당 서비스의 `wss://` 주소를 입력합니다. HTTPS 페이지에서는 `wss://`를 사용하세요. 무료 호스팅의 절전으로 첫 연결이 지연될 수 있습니다.

## 패치노트와 참고 자료

패치노트 데이터는 `public/patches.json`에서 관리합니다. 참고 요청된 기존 게임은 https://last-signal.naitoria.chatgpt.site/ 입니다. 구현 시 환경의 네트워크 정책이 해당 사이트 접근을 차단하여 기존 UI·데이터는 아직 반영하지 못했습니다. 접근이 가능해지면 기존 형식과 데이터 구조를 확인하고 적용할 수 있습니다.
